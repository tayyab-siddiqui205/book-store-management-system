# book-store-management-system
Flutter-based Book Store Management System with Firebase Authentication, Cloud Firestore, book categories, search, cart, wishlist, reviews, and admin management.

## Features
- User authentication and account management
- Browse books by category
- Search and discover books
- Shopping cart and wishlist
- Book ratings and reviews
- Admin dashboard for book management
- Firebase Authentication and Cloud Firestore integration
- Cloudinary image hosting

## Tech Stack
- Flutter & Dart
- Firebase Authentication
- Cloud Firestore
- Provider for state management
- Cloudinary

## Project Purpose
This project demonstrates mobile application development, authentication, database integration, state management, and book inventory management.
